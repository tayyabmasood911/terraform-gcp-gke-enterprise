# Security Policy

## Supported Versions

Security fixes and updates are actively maintained on the latest stable releases of this repository.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of this infrastructure and code repository seriously. If you discover a vulnerability or potential security risk, please report it responsibly:

1. **Email:** Send details to **tayyabmasood911@gmail.com** with the subject line `[SECURITY] Potential Vulnerability in <repository-name>`.
2. **Details:** Include a detailed description of the issue, affected files/components, steps or proof-of-concept to reproduce, and any suggested remediations.
3. **Response Timeline:**
   - **Initial Acknowledgment:** Within 48 hours of receipt.
   - **Triage & Status Update:** Within 5 business days.
   - **Resolution & Release:** Targeted patch release within 30 days depending on severity.
4. **Responsible Disclosure:** Please do not disclose vulnerabilities publicly or open public GitHub issues prior to coordinated disclosure and resolution.
